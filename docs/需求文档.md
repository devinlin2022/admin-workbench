# 行政个人工作台（网页版）需求文档

> 版本：v1.0　｜　整理日期：2026-11-08　｜　来源：微信图文需求截图（两张）
> 说明：原文为口语化描述，本文按产品需求文档结构重排、补全字段与验收口径，原意不改。

## 一、项目概述

为行政岗位（尤其是一人多岗的中小企业行政）搭建一个**个人工作台网页版**，把日常散落在 Excel、微信、纸质台账里的行政事务集中到一处：日历、待办、模板、制度、合同档案、固定资产、费用台账、员工活动，一站管理。

**核心定位**：单机可用、纯前端、数据留在本机、不依赖服务器与网络。

**目标用户**：1–3 人规模的行政团队，或兼任行政的 HR / 前台 / 办公室主任。

**使用场景**：每天上班先看看板（今天该做什么、有哪些到期了）→ 处理待办 → 调用模板出通知 → 归档合同与资产 → 月底出费用汇总。

---

## 二、功能需求

共 10 个模块，编号沿用原需求。

### 1. 工作看板（首页）

作为默认落地页，一屏汇总四类信息：

| 区块 | 内容 |
|---|---|
| 日历 | 公历 + 农历 + 法定节假日/调休标记（lunar.js 提供） |
| 待办事项 | 今日待办清单，可直接勾选完成 |
| 会议室预约 | 各会议室**实时状态**：空闲 / 使用中 / 下一场时间与预约人 |
| 行政资讯 | 政策与行业动态流，如"大厂行政新鲜事儿""社保公积金最新政策" |

要求：四区块可同时可见，不需滚动即可看到今日重点；到期/逾期项在首页高亮。

### 2. 待办事项

- 今日待办、进度跟踪（未开始 / 进行中 / 已完成）
- 支持**优先级标签**（高 / 中 / 低，用颜色区分）
- 支持**自动化提醒**：到期前通过浏览器原生通知推送
- 建议补充：截止日期、所属模块关联（如关联某份合同）、重复任务（每周/每月）

### 3. 模板中心

- 内置模板：会议通知、放假通知、会议纪要、月报、以及后续可扩展的各类行政文书
- 支持**在线编辑**（Markdown 编辑器，marked 渲染 + DOMPurify 净化）
- 支持**版本管理**：同一模板保留历史版本，可回滚、可对比
- 支持**分类存档**：按类型/部门分组

### 4. 制度管理

- 收录各类内部制度：印章管理制度、保洁管理制度、前台管理制度等
- 分类浏览 + 全文搜索 + 在线查看
- 建议补充：版本号与生效日期、制度更新提醒

### 5. 档案管理

- **合同管理**：合同登记、合同分类、**到期提醒**（到期前 N 天预警）
- 支持**搜索功能**：按名称、相对方、编号、分类检索
- 附件采用**本地路径引用**（不存二进制，只记录路径），点击可调起本机打开

### 6. 固定资产管理

- 固定资产台账：电脑、桌椅、车辆等
- 字段建议：资产编号、名称、类别、规格、购入日期、原值、使用人/存放位置、状态（在用/闲置/报废）
- 建议补充：按类别/使用人筛选、导出 Excel

### 7. 费用台账

- **台账明细**：逐笔记账（日期、类别、金额、事由、报销状态、凭证附件路径）
- **费用汇总**：按周期/类别/部门汇总
- **费用类别排行**：各类别支出占比与排名
- **月度费用趋势**：Chart.js 折线/柱状图
- **支持数据分析**：趋势对比、同比/环比、异常支出提示
- 金额字段使用等宽字体，右对齐

### 8. 后勤管理

- **食堂管理**：菜单排期、订餐统计、供应商/结算记录
- **设施设备维护**：报修登记、维修进度跟踪、保养计划与提醒（空调、电梯、消防设施年检等）
- **应急预案**：预案文档存档、联系人清单、演练记录

### 9. 员工活动 / 福利

- 重大节日福利采购
- 周年庆策划、生日策划
- 团建活动
- 员工体检安排

### 10. 其他行政事务

兜底模块，收纳未归类的杂项事务（快递、名片、工位、饮用水、绿植等）。

## 三、技术栈要求（硬性约束）

| 项 | 要求 |
|---|---|
| 框架 | **纯 HTML + CSS + 原生 ES Modules**，**不使用任何构建工具**（无 webpack/vite/npm build） |
| 依赖方式 | 本地化 vendor 库，文件直接放入项目目录引用 |
| 农历/节假日 | lunar.js |
| 图表 | Chart.js |
| Markdown | marked + DOMPurify（渲染 + XSS 净化） |
| Excel 导出 | SheetJS（支持 xlsx 多 Sheet 导出） |
| 主存储 | **localStorage** |
| 附件 | 只存本地路径引用，不存二进制 |
| 可选增强 | File System Access API（绑定工作目录，实现真实文件读写） |
| 资讯与提醒 | RSS 代理拉取行政资讯 + 浏览器原生通知实现到期提醒 |

**部署形态**：双击 `index.html` 或本地静态服务器即可运行，无需安装环境。

## 四、视觉规范

风格关键词：**隐奢高光 → 商务风**（暖米白底 + 墨黑字 + 少量金黄点缀）。

| 角色 | 颜色 | 用途 |
|---|---|---|
| 主背景 | `#E3DEDA` 暖米白 | 页面底色 |
| 卡片背景 | `#EFEBE6` | 卡片 / 面板 |
| 文字 | `#252219` 墨黑 | 主文字 |
| 强调色 | `#F2CF4D` 金黄 | 主按钮、选中态、关键徽章（**克制使用**） |
| 信息色 | `#1E5BFF` 亮蓝 | 链接、信息提示 |
| 状态色 | 沉绿 / 琥珀 / 砖红 | 成功 / 将到期 / 已到期 |

字体：系统中文无衬线（PingFang SC / 微软雅黑），金额使用 SF Mono 等等宽字体。

> 状态色原文只给了名称未给色值，建议取：沉绿 `#2F6B52`、琥珀 `#C08A2E`、砖红 `#B4432F`（待确认）。

## 五、数据与非功能要求

1. **离线优先**：断网状态下除资讯/RSS 外全部功能可用。
2. **数据自持**：全部数据存于本机 localStorage，不上传任何服务器。
3. **备份可迁移**：提供"导出全部数据为 JSON / 从 JSON 导入"的备份还原入口（防止清缓存丢数据）。
4. **数据规模**：单模块千级记录下操作无明显卡顿（localStorage 容量约 5MB，需在文档中提示容量上限）。
5. **响应式**：桌面优先（≥1280px），兼容 1024px 笔记本；手机端可只读查看。
6. **可维护**：模块以独立 JS 文件拆分，新增模块不需改动构建流程。

## 六、优化建议（原文授权"有可以优化的你再优化一下"）

按投入产出排序，建议一并纳入首版：

1. **全局搜索 / 命令面板**（Ctrl+K）：一处搜待办、合同、制度、资产、模板，行政最高频痛点。
2. **首页"到期雷达"**：把合同到期、资产保修到期、证照年检、体检复检等统一成一个"未来 30 天到期"列表，比分散在各模块更有效。
3. **快速录入**：右下角常驻"＋"，一键新建待办/费用/合同。
4. **重复任务**：月度对账、季度盘点、每周例会通知等设为周期任务，自动生成。
5. **数据一键导出**：各台账支持导出 Excel（多 Sheet 汇总），方便向上汇报。
6. **PWA 化**：加 manifest + Service Worker，可安装到桌面像 App 一样打开。
7. **主题与密度**：提供"紧凑/舒适"两档信息密度，适配小屏笔记本。
8. **数据健康检查**：合同缺失附件路径、费用缺失类别等给出"待补全"清单。
